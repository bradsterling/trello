# Trello / QuickBooks integration

This project contains the Ledgerflow Trello-to-QuickBooks Chrome extension, its Firebase functions, and Supabase backend assets.

## Components

- `trello-quickbooks-extension/` — unpacked Manifest V3 Chrome extension
- `firebase-functions/` — Firebase backend functions
- `supabase/` — database schema and Edge Function configuration

For extension setup and testing, see [`trello-quickbooks-extension/README.md`](trello-quickbooks-extension/README.md).
